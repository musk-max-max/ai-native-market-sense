# Market Sense 设计系统 v2（system-v2）

> 适用范围：C 端 H5（`web/h5`）+ 中后台控制台（`web/console`）。
> 基准尺寸：移动端 **390 × 844**；中后台 **1440 × 900**。
> 版式参照东方财富移动端 / PC 端；组件基于 antd-mobile（C 端）与 antd 5（中后台）。
> 本文档是**规范**，不是实现：只给 token、规则与组件约定，落地代码由各端接入。

---

## 1. 设计原则（四条，优先级从高到低）

| 原则 | 含义 | 一票否决的例子 |
| --- | --- | --- |
| **合规优先** | 免责声明、AI 标识（`ai.generated`）、as_of 口径、退订入口，位置、对比度、可见性**不可协商**。任何视觉美化不得挤压、折叠、降透明度、加关闭按钮。 | 把免责声明做成 `<Collapse>` 默认收起；给 AI 标识加「×」 |
| **客观** | 界面只陈述事实与口径，**不出现诱导性视觉暗示**。禁用词：机会 / 必涨 / 推荐 / 抄底 / 潜力 / 涨停敢死队。禁用视觉：上涨方向箭头装饰、金色/渐变「机会」标签、心跳/火箭动效、把涨跌做成游戏化进度条。 | 首页放「今日机会」黄金卡片；涨跌色叠加闪烁动画吸引下单 |
| **克制** | 一屏一个主任务。颜色只承载「涨/跌/中性/危险」四种语义，不做装饰色。留白优先于分隔线，分隔线优先于卡片阴影。 | 用 5 种彩色标签区分板块；卡片套三层阴影 |
| **可追溯** | 每一个数值都能回答「这是什么、什么时候、从哪来」。数值必带来源标识 + as_of；缺失值显示 `—` 并说明，绝不用 `0` 冒充。 | 只显示价格不显示 as_of；数据缺失时显示 `0.00` |

> 现有代码已落实其中大部分（`lib/copy.ts` 单一文案来源、`DataGapCard` 受控缺口枚举、`AiGeneratedBadge` 无关闭路径）。v2 把这些**从代码约定提升为设计规范**，使设计与实现有同一把尺。

## 2. 色彩 Token

### 2.1 语义色（唯一权威表）

涨跌色遵循中国习惯 **红涨绿跌**。所有正文/数值用途必须满足 **4.5:1**；仅作 3:1 的大号数值（≥24px bold）场景单列。

| Token | 浅色 | 深色 | 用途 | 浅色对白底对比度 | 深色对 `#131a22` 对比度 |
| --- | --- | --- | --- | --- | --- |
| `--up` | `#d92b20` | `#ff8b82` | 涨：正文/小号数值 | **4.86:1** ✅ | 7.7:1 ✅ |
| `--up-strong` | `#e63e31` | `#ff8b82` | 涨：≥24px 大号价格（东财红） | **4.12:1 ⚠️ 仅大字达标**（≥24px 常规或 ≥18.66px bold）；**正文字号禁用** | 7.7:1 ✅ |
| `--up-weak` | `#fdecea` | `#3a1c1a` | 涨背景色块（涨幅胶囊底） | — | — |
| `--up-weak-text` | `#c5302b` | `#ffc9c4` | 彩色底上的涨文字 | **4.79:1** ✅（对 `#fdecea`） | ✅ |
| `--down` | `#00804a` | `#3ddc97` | 跌：正文/小号数值 | **5.02:1** ✅ | 9.9:1 ✅ |
| `--down-strong` | `#00a854` | `#3ddc97` | 跌：≥24px 大号价格 | **3.12:1 ⚠️ 正文不达标**（仅大字）；压 `--down-weak` **2.79:1，任何字号禁用** | 9.9:1 ✅ |
| `--down-weak` | `#e6f6ec` | `#102e20` | 跌背景色块 | — | — |
| `--down-weak-text` | `#00794a` | `#b8f0d0` | 彩色底上的跌文字 | **5.48:1**（对白） / **4.89:1**（对 `#e6f6ec`） ✅；对 `--down` 仅 4.48（临界），勿混用 | 11.45:1 ✅ |
| `--flat` | `#5c6370` | `#9aa3ad` | 平盘 / 中性 / muted 正文 | 6.05:1 ✅ | ✅ |
| `--text` | `#1f2329` | `#e7eaee` | 主正文 | 15.8:1 ✅ | ✅ |
| `--text-muted` | `#5c6370` | `#9aa3ad` | 次要说明、口径、来源 | 6.05:1 ✅ | ✅ |
| `--text-subtle` | `#6b7280` | `#8a93a0` | 仅 ≥13px 的辅助行，**仅白底** | 4.83:1 ✅（压 `--bg` 4.46 / `--surface-2` 4.27 **不达标**） | 5.64:1 ✅ |

> **关键改动 vs 现状**：现有 h5 `tokens.css` 用 `--up:#b3261e` / `--down:#0f6b3d`（偏暗、不像行情色），console 用 `--up:#d64545` / `--down:#1f9d55`。v2 统一两端为上表，并**新增 `--*-weak-text` 一层**——因为在浅色胶囊底上直接用 `--down-strong:#00a854` 只有 **2.79:1**（严重不达标），必须换深一档文字色。

### 2.2 品牌色

| Token | 值 | 用途 |
| --- | --- | --- |
| `--brand` | `#1677ff` | 选中态指示条、图标、焦点装饰（**仅图形/装饰**，非文本 3:1；文字与按钮底见 `--brand-deep`） |
| `--brand-deep` | `#0f5fd6` | **文字级主色**：链接、主按钮底（白字 5.79:1）、`--brand-weak` 上的文字（5.09:1） |
| `--brand-weak` | `#e8f1ff` | 选中行底、激活 Tab 底 |
| `--brand-emphasis` | `#e63e31` | 东财红，**仅**用于品牌强调位（首页顶部指数涨、TabBar 激活点）。图形用途 ≥3:1 达标；**作按钮底时白字仅 4.12:1，只允许 ≥18.66px bold，普通 CTA 改用 `--brand-deep`**。**不得**用于「机会/推荐」类语义 |
| `--brand-contrast` | `#ffffff` | 品牌色上的文字 |

> 白字压 `#1677ff` 实测 **4.10:1**——**不达正文 4.5:1，且 14px/500 不构成 WCAG 大字**（大字 = ≥24px 常规或 ≥18.66px bold）。规则：① 链接文字、主按钮底、TabBar 选中文字一律用 `--brand-deep:#0f5fd6`（对白 **5.79:1**）；② `--brand:#1677ff` 只用于图形/选中条/焦点装饰（非文本对比 3:1 达标）；③ `--brand` 压 `--brand-weak` 仅 **3.61:1**，激活底上的文字必须用 `--brand-deep`（**5.09:1**）。

### 2.3 背景与边框

| Token | 浅色 | 深色 |
| --- | --- | --- |
| `--bg` | `#f4f6f8` | `#0b0f14` |
| `--surface` | `#ffffff` | `#131a22` |
| `--surface-2` | `#eef1f5` | `#1b2430` |
| `--border` | `#d7dde5` | `#2a3542` |
| `--border-strong` | `#aab6c4` | `#465463` |
| `--border-control` | `#8a929c` | `#8a929c` |

东方财富版式特征 = **白底卡片 + 浅灰画布 + 无彩色分区**。禁止用彩色背景划分板块（除涨跌胶囊）。

`--border-control(#8a929c)` 专用于**输入框/可交互控件边界**（对白 3.15:1，满足 WCAG 1.4.11 的 3:1）；`--border`(#d7dde5 1.37:1)、`--border-strong`(#aab6c4 2.06:1) 仅作装饰性分隔，**不得**作为控件唯一可见边界。

### 2.4 状态色（中后台）

沿用 antd 语义并锁定对比度：`--warning-text:#7a4d00`（对 `#fff7e6` ≥4.5:1）、`--danger-text:#a12622`、`--success-text:#1c6b3d`。Badge / Tag 一律使用 **`color + colorBg`** 双 token，不允许白字压浅底。

## 3. 字体 Token

```css
--font-sans: -apple-system, BlinkMacSystemFont, 'PingFang SC', 'Hiragino Sans GB',
             'Microsoft YaHei', sans-serif;
--font-mono: ui-monospace, SFMono-Regular, Menlo, Consolas, monospace;
--font-numeric: 'DIN Alternate', 'Helvetica Neue', var(--font-sans); /* 行情数字 */
```

字号阶梯（移动端 / 中后台共用比例，中后台整体 −1px）：

| Token | H5 | 中后台 | 用途 |
| --- | --- | --- | --- |
| `--fs-display` | 28 / bold | 24 / bold | 个股最新价 |
| `--fs-title` | 18 / semibold | 16 / semibold | 卡片标题、页面 H2 |
| `--fs-body` | 15 / regular | 14 / regular | 正文、表格单元格 |
| `--fs-caption` | 13 / regular | 12 / regular | as_of、来源、免责正文（**不得再小**） |
| `--fs-tag` | 11 / medium | 11 / medium | 标签、Badge（仅短语） |

规则：
- **所有数字用 `--font-numeric` + `font-variant-numeric: tabular-nums`**，保证表格/分时数值纵向对齐（东财版式核心特征）。
- 免责声明、as_of、来源标识的字号**下限 13px（H5）/ 12px（中后台）**，且对比度按 §2.1 全档达标——这是合规红线，不允许用 `--fs-tag` 11px 弱化。

## 4. 间距与栅格

8pt 基准，4pt 半档：

`--space-1:4 · --space-2:8 · --space-3:12 · --space-4:16 · --space-5:24 · --space-6:32`

| 场景 | 值 |
| --- | --- |
| H5 页面左右安全边距 | 16（`--space-4`） |
| H5 卡片间距 | 12（`--space-3`） |
| H5 卡片内边距 | 16，标题与内容间 8 |
| H5 卡片圆角 | 14（现有值保留）；小元素 10；胶囊 999 |
| H5 底部 TabBar 高度 | 50 + `env(safe-area-inset-bottom)` |
| H5 顶部 NavBar 高度 | 44 + 状态栏 |
| 中后台侧栏宽 | 232（沿用现有 `--sidebar-width`） |
| 中后台顶栏高 | 56（沿用现有 `--topbar-height`） |
| 中后台内容栅格 | 24 栏，gutter 16；StatCard 跨 6 栏（一屏 4 个） |
| 中后台卡片圆角 | 8；表格行高 44 |

断点：H5 只服务 `<768px`；`≥768px` 时 H5 居中于 640 容器（沿用现有 `--max-width:640px`）。中后台 `<1200px` 侧栏收起为图标栏（64），`<992px` 给出「请使用桌面端」提示而非强行响应。

## 5. 组件规范

### 5.1 Button

| 变体 | 用途 | 规格 |
| --- | --- | --- |
| `primary` | 每屏**唯一**主操作（搜索、提交审批） | 底 `--brand`，白字，高 44（H5）/32（中后台），圆角 10/6 |
| `default` | 次操作 | 白底 + `--border-strong` + `--text` |
| `ghost-danger` | 高危（回滚、发布到生产） | 透明底 + `--danger-border` + `--danger-text`；**必须**套 `DoubleConfirm` |
| `text` | 行内跳转、自选 ⭐ | 无底，`--brand` 文字 |

禁令：不得用 `--up`/`--down` 做按钮底色（涨跌色只表达行情，不表达动作）；不得用 `--brand-emphasis` 红 CTA 承载「买入/机会」语义。

### 5.2 Card

- 白底 `--surface`，圆角 14（H5）/8（中后台），边框 1px `--border`，**无阴影或仅 `--shadow` 一档**。
- 结构固定三段：`header（title + 可选右侧 as_of）` → `body` → `footnote（来源/口径/免责）`。
- **行情类卡片 header 右侧必须放 as_of**（13px `--text-muted`），body 内数值必带来源标签。
- 允许的 header 右侧元素只有：as_of、时间粒度切换、缺口标识。**不允许**「更多机会 →」「荐股」入口。

### 5.3 Table（中后台 antd `Table`）

- 行高 44，表头 `--surface-2` 底 + `--text-muted` 12px medium。
- 数值列右对齐 + `tabular-nums`；时间列 `--font-mono`。
- **审计日志表**（详见 console-v2 §5）：`时间 / 动作 / 对象 / 操作者 / 详情 / 结果`，操作者用 `ActorBadge`（human=头像，agent=`AI` 方标）。agent 行左侧加 2px `--brand-emphasis` 竖条，扫读时能立刻识别「机器改了什么」。
- 分页固定 `showSizeChanger` 关闭、pageSize 20，避免审计导出口径漂移。
- 状态列用 `StatusBadge`，色只取自 §2.4。

### 5.4 Modal

- 高危确认（发布/回滚/驳回）：必须走现有 `DoubleConfirm` 形态——第一步勾选「我已阅读影响面」，第二步输入危险词（`dangerConfirmWord`）。标题用 `--danger-text`。
- 审批通过 Modal 顶部**固定渲染 diff**（`DiffViewer`），不允许折叠到「查看详情」。
- Modal 内禁止出现新的导航（不允许在弹窗里跳走后丢失审批上下文）。

### 5.5 Badge / Tag

| 形态 | 用途 | 颜色 |
| --- | --- | --- |
| 涨跌胶囊 | 涨跌幅 | `--up-weak` 底 + `--up-weak-text` 字 / `--down-weak` 底 + `--down-weak-text` 字 |
| `StatusBadge` | 草稿/待校验/待审批/已发布/已回滚 | 灰 / warning / brand / success / danger |
| `LevelBadge` | 风险等级 L0–L3 | 灰→warning→danger 阶梯 |
| **AI 标识** | `AI 生成 · 仅供参考` | 方形 `AI` 图标（`--brand-emphasis` 底白字）+ 文字 `--text-muted`；**无关闭、无折叠、无透明度** |
| 缺口标识 | 数据缺口 | `--surface-2` 底 + `--flat` 虚线边框，中性、不警示 |

> 涨跌胶囊**不加箭头图标**：箭头是方向装饰，会强化「看涨暗示」。只允许 `+2.31%` / `−1.05%` 的正负号承载方向（现有 `formatChangePct` 已是此形态，固化为规范）。

### 5.6 空态 / 缺口 / 错误（三态不可混）

| 形态 | 语义 | 视觉 |
| --- | --- | --- |
| Loading | 数据在途 | 骨架屏，**不出现在个股页首屏 6 元素区**（现有 A12 契约） |
| Empty | 用户确无数据（空自选） | 插图 + 一个 CTA |
| **DataGap** | 数据应存在但未接入/未授权 | 中性虚线卡 + 受控原因枚举（`pending_batch` / `permission` / `upstream_missing` / `not_integrated` / `no_coverage`） |
| Error | 请求失败 | 按 HTTP status 映射文案；403 走 `EntitlementNotice`（原样 Problem 文案），不给「重试」 |

> 现有代码的三态纪律非常好（`DataGapCard` 受控枚举、403 不渲染数字）。v2 的改进是给 DataGap 一个**专属视觉**（虚线 + 中性灰），使它和 Error/Empty 在扫读时不可混淆——现在三者共用 `.card` 外观，用户分不清「没数据」和「没权限」。

## 6. 动效

原则：**只做状态反馈，不做注意力劫持。**

| 场景 | 动效 | 时长 |
| --- | --- | --- |
| 涨跌价变化 | 数字滚动 + 颜色淡入（`--up-strong`/`--down-strong` → 200ms 后回 `--up`/`--down`） | 240ms，一次性 |
| 下拉刷新 | antd-mobile `PullToRefresh` 原生 | 系统 |
| 上滑加载 | `InfiniteScroll`，底部 24px 灰条 + `--text-muted`「加载中」 | — |
| 卡片进入 | 无（禁 stagger 入场，行情页要的是信息密度） | — |
| 高危 Modal | 遮罩 240ms 淡入，无弹跳 | — |

**禁止**：涨跌闪烁循环、涨停红色脉冲、数字老虎机效果、任何指向性弹跳。这些是诱导性视觉暗示，触碰投顾红线。

## 7. 无障碍与合规硬门槛（设计评审 checklist）

1. 免责声明 / AI 标识 / as_of / 退订入口：位置显眼、无关闭、无折叠、无低对比。
2. 全站搜索禁用词：机会、必涨、推荐、抄底、潜力、稳赚、牛股、涨停敢死队。
3. 每个数值旁有来源标识（`sourceLabel` 受控映射）+ as_of。
4. 涨跌色按 §2.1；`--*-weak-text` 用于彩底，禁止直接用 `--up-strong`/`--down-strong` 压彩底。
5. 缺失值 `—` + 说明，禁止 `0`。
6. 触控目标 ≥44×44（H5）；表格行 ≥44 高（中后台）。
7. 焦点环 `--focus` 2px，不可 `outline:none`。
8. `prefers-color-scheme` 深色全档对比度达标（深色涨跌色已单独调亮）。

## 8. 对比分析（现有方案 vs v2）

现有基线：`web/h5/src/styles/tokens.css` + `web/console/src/styles/tokens.css`（两份各自为政的临时 token，注释均标「A10 交付后替换」）。

| # | 现状 | v2 改进 | 价值 |
| --- | --- | --- | --- |
| 1 | **两套 token 各自为政**：h5 `--accent:#0b6357`（青绿）、console `--accent:#2f6bff`（蓝），涨跌色也不一致（h5 `#b3261e`/`#0f6b3d` vs console `#d64545`/`#1f9d55`） | 统一语义色表（§2.1），C 端/中后台共用一套涨跌/中性/状态色，品牌色固定 `#1677ff` | 跨端视觉一致；品牌色不再「一边青一边蓝」；新页面无需再猜用哪套 |
| 2 | **涨跌色对比度未验证**，且 `--down:#00a854`（东财绿）对白底仅 **3.12:1**，压浅色底更低至 **2.79:1**——不满足 4.5:1 硬约束 | 正文用 `--down:#00804a`（5.02:1）、`--up:#d92b20`（4.86:1）；新增 `--*-weak-text` 彩底专用文字层 | 合规红线（对比度 4.5:1）从「大概没问题」变成**可量化验收**；东财品牌感（大字用 `#e63e31`）与可读性兼得 |
| 3 | 现有 `--up`/`--down`（`#b3261e`/`#0f6b3d`）偏暗，**不像行情色**，用户扫读时涨跌识别慢 | 大号数值 `--up-strong:#e63e31`/`--down-strong:#00a854`（东财红绿），正文用深一档 | 行情页视觉母语回到东财习惯，同时小字不牺牲对比度 |
| 4 | 无 `--font-numeric`，无 `tabular-nums` 约定；数字与中文混排基线不齐 | 新增 `--font-numeric`（DIN Alternate）+ 全站数字 `tabular-nums` | 表格/分时/榜单数字纵向对齐（东财版式核心特征） |
