# 免费研报与财经资讯 Web Search 来源指南

> **文档定位**：本平台获取**研报 / 行业研究 / 财经资讯 / 上市公司披露**的权威来源指南。用于替代采购 tushare 的资讯（¥1000/年）、政策法规库（¥1000/年）、券商研报库（¥500/年）三类独立权限——**不采购，改用 Web Search 抓公开免费源**。
> **适用对象**：A20/A21/A22 金融研究子 agent、AI 综合研判模块、盘前简报、政策解读等所有需要外部资讯/研报的功能点。
> **决策记录**：见 `data-source-gap-matrix.md` §5 决策 D-3。编制日期 2026-11-05。

## 使用目的

用于搜索公开研报、行业研究、财经资讯和上市公司披露资料。优先获取可公开访问的网页与 PDF 原文。

"免费"指平台提供部分公开内容，不代表全站报告、全文下载或 API 均免费。访问权限以实际页面为准。

## 搜索流程

1. 使用财联社、华尔街见闻发现事件和关键词。
2. 使用东方财富、慧博、艾瑞、信通院查找研究与行业背景。
3. 使用巨潮资讯、公司官网、交易所或监管机构原文核实关键事实。
4. 输出结论时附原始来源链接、发布日期及数据所属期间。

```text

site:iresearch.cn 消费 行业研究

site:wallstreetcn.com 美联储 利率
site:cninfo.com.cn 公司名称 年度报告
```

年份、公司名称及主题词应根据任务替换。搜索引擎对 `site:`、`filetype:` 等语法的支持可能不同，必要时拆分查询。

## 来源使用规则

- 优先引用报告原文、公司公告、监管文件及官方统计资料。
- 聚合平台用于发现报告；能够找到原始发布机构版本时，优先引用原始版本。
- 只有摘要时明确标注"基于摘要"，不得声称已阅读全文。
- 区分事实、机构预测、分析师观点和自身推断。
- 区分发布日期与数据所属期间，避免将历史数据当成当前数据。
- 同一报告被多个网站转载，按一个来源计算。
- 关键数字尽量回溯至原始表格、公告或统计资料，并保留单位与统计口径。
- 财经快讯作为检索线索，关键结论应进一步核对原始来源。
- 无法获取全文时说明限制，不编造报告内容、页码或引用。
- 不绕过登录、付费墙或访问限制。
- 网页免费访问不等于提供免费 API；批量抓取与接口接入需另行核实使用规则。

## 对本平台的落地含义（补充说明）

1. **替代的付费权限**：tushare 资讯（¥1000/年）+ 政策法规库（¥1000/年）+ 券商研报库（¥500/年）= 合计 ¥2500/年，**均不采购**，改由 Web Search 按本指南抓公开源。
2. **AI 输入方式**：研究 agent（A20/A21/A22）在做盘前简报、政策解读、行业研究、综合研判时，用 Web Search 按上述流程检索公开源，把抓到的内容作为 AI 输入语料。
3. **合规与可溯源**：所有基于 Web Search 的 AI 输出必须附**原始来源链接 + 发布日期 + 数据所属期间**；区分"事实 / 机构预测 / 分析师观点 / AI 自身推断"；只有摘要时标"基于摘要"。
4. **as_of 仍强制**：Web 抓到的资讯同样带发布时点，进入 AI 与展示层时沿用 `as_of` 约束，不得把旧数据当当前。
5. **技术注意**：网页免费访问 ≠ 免费 API。批量抓取/接口接入前需核实各站使用规则，不绕过付费墙，控制抓取频率。
6. **与 tushare 结构化数据的分工**：tushare 提供**结构化行情/财务/资金数据**（15000 内），Web Search 提供**文本类资讯/研报/政策语料**。两者互补，共同构成研究 agent 的输入。
