# 东方财富网（eastmoney.com）C 端数据展示层级研究

> **文档目的**：为产品与数据团队梳理东方财富网面向个人投资者（C 端）的数据展示层级，作为竞品对标与数据源规划参考。
> **研究方法**：通过 web_fetch 抓取东方财富官网及核心频道真实页面结构，基于抓取内容归纳。抓取日期：2026-11-05。
> **确定性标注**：文中标注「✅ 已抓取确认」的层级基于真实页面；标注「⚠️ 基于公开认知」的部分未能抓取到具体页面，确定性较低，仅供参考。

---

## 1. 顶层结构总览

东方财富 C 端数据展示可归纳为 **9 大数据大类**，对应其主站导航与子站点：

| # | 数据大类 | 对应子站/频道 | 核心定位 | 更新频率 |
|---|---|---|---|---|
| 1 | 沪深京行情（含全球指数） | quote.eastmoney.com/center | 实时行情中枢 | 实时（盘中） |
| 2 | 个股详情 | quote.eastmoney.com/{sh\|sz\|bj}xxxxxx.html | 单标的深度数据 | 实时 + 日频 |
| 3 | 板块 / 行业 / 概念 | data.eastmoney.com 板块资金流 | 主题分类与资金 | 实时 |
| 4 | 资金流向 | data.eastmoney.com/stock/ | 主力/北向资金 | 实时 + 日频 |
| 5 | 龙虎榜与席位 | data.eastmoney.com/stock/lhb | 异动与游资追踪 | 日频（盘后） |
| 6 | 基金 | fund.eastmoney.com | 公募/ETF/FOF 全谱系 | 日频（净值） |
| 7 | 数据中心（宏观/排行/统计） | data.eastmoney.com | 结构化榜单与经济数据 | 日频 / 月频 |
| 8 | 债券 / 期货 / 外汇 / 全球市场 | bond\|futures\|forex\|global 子站 | 跨资产类别 | 实时/延时 |
| 9 | 资讯 / 股吧 / 研报 | news、guba、research 子站 | 内容与社区 | 实时 |

> 说明：东方财富将「行情中心」与「数据中心」分为两大入口——**行情中心偏实时价格发现**，**数据中心偏结构化榜单与统计**，这是理解其信息架构的关键。

## 2. 数据大类详解

### 2.1 沪深京行情中心 ✅ 已抓取确认

**覆盖内容**：沪深京三市全部股票实时行情、全球指数、涨跌幅榜、资金异动、牛熊风向标。

**典型展示形式**：

| 子类 | 展示形式 | 典型字段 | 更新频率 |
|---|---|---|---|
| 指数行情（全球） | 横向滚动指数条 | 最新价、涨跌额、涨跌幅 | 实时 |
| A股实时行情列表 | 可排序大表格（gridlist） | 代码、名称、最新价、涨跌幅、涨跌额、成交量(手)、成交额、振幅、最高/最低、今开/昨收、量比、换手率、市盈率(动态)、市净率 | 实时 |
| 涨跌幅榜 | 排行榜 | 按涨跌幅/成交额/换手率/量比排序 | 实时 |
| 资金异动榜 | 实时流式列表 | 最新价、涨跌幅、主力净流入、净占比 | 实时 |
| 大单异动快讯 | 时间戳流（Tick 流） | 时间、股票、异动类型（火箭发射/快速反弹/高台跳水/封涨停板/打开涨停/大笔买入/大笔卖出/有大买盘/有大卖盘/60日新高） | 实时（秒级） |
| 融资融券（牛熊风向标） | 表格 | 本日融资余额、融资买入额、融券余量余额、融资融券额（分沪/深/京/三市） | 日频 |
| 停复牌/新股/公告速览 | 分类小表 | 停复牌、年报季报、新股发行、股份变动、股东大会、重要公告 | 日频 |

> **亮点**：行情中心首页集成了**秒级「大单异动」文字流**（如「10:34:54 光洋股份 封涨停板 21.49元」），是面向短线交易者的高频信息产品。

### 2.2 个股详情页 ✅ 已抓取确认（样本：贵州茅台 sh600519）

个股页是东方财富信息密度最高的页面，纵向整合多个数据模块：

| 模块 | 子类 | 典型字段 / 展示形式 | 更新频率 |
|---|---|---|---|
| **实时报价** | 盘口五档 | 委比、委差、卖五~卖一、买一~买五（价/量） | 实时（Tick） |
| | 成交明细 | 最新、均价、涨幅、总手、金额、换手、量比、最高/最低、今开/昨收、涨停/跌停、外盘/内盘 | 实时 |
| | 分时成交 | 逐笔时间、价格、方向箭头、手数 | 实时 |
| **估值指标** | 三档 PE | 动态市盈率、静态市盈率、滚动市盈率（附计算口径说明） | 实时 |
| **公司核心数据** | 基本面卡 | 收益、PE(动)、每股净资产、市净率、总营收(同比)、净利润(同比)、毛利率、净利率、ROE、负债率、总股本/流通股、总市值/流通市值、每股未分配利润、上市时间 | 季频/日频 |
| **股东情况** | 股东户数趋势 | 股东户数、较上期(%)（按报告期 26-09-30 / 26-06-30） | 季频 |
| **十大流通股东** | 机构类型拆分 | 公募/私募/社保/QFII 持股家数 | 季频 |
| **行业对比** | 四分位属性 | 总市值、净资产、净利润、PE、PB、毛利率、净利率、ROE + 行业排名(如 1\|19) + 高/较高/较低/低四分位标注 | 季频 |
| **资金流向** | 单/大单拆分 | 主力/超大单/大单/中单/小单 净流入额与净占比、实时成交分布图 | 实时 |
| **K线/分时** | 图表 | 分时、日K、周K、月K、分钟K（含 MA/MACD/KDJ 等技术指标） | 实时 |
| **同板块联动** | 关联个股 | 所属行业(如白酒Ⅱ)相关个股涨跌幅排行 | 实时 |
| **简名/公司变更** | 历史记录 | 简称变更历史、两融标识、沪股通标识、交易状态 | 事件驱动 |
| **社区** | 股吧 | 发帖、评论区（含合规声明） | 实时 |

> **亮点**：
> - **三档 PE（动态/静态/滚动）并附计算公式说明**，对 C 端投资者教育友好。
> - **行业四分位属性图**：把每个基本面指标映射到「高/较高/较低/低」，并用 tooltip 解释指标含义，是少见的可视化基本面定位产品。
> - 个股页直接内嵌**资金流向五档拆解**与**实时成交分布图**，无需跳转。

### 2.3 板块 / 行业 / 概念 ✅ 已抓取确认

**覆盖内容**：东方财富维护了一套庞大的**概念分类体系**（数百个概念标签），并按行业/概念/地域三维度组织板块资金流。

**展示形式**：
- 概念字典（按拼音首字母 A–Z 索引），示例概念：AI芯片、AIGC概念、人形机器人、低空经济、固态电池、CPO概念、商业航天、数据要素、中特估、华为概念、DeepSeek概念 等。
- **板块资金流向**：分「行业 / 概念 / 地域」三类，展示主力净流入排行。
- 昨日涨停、昨日连板、昨日炸板、昨日首板 等**涨停板复盘类概念标签**。

| 子类 | 展示形式 | 字段 | 更新频率 |
|---|---|---|---|
| 概念分类 | 拼音索引标签云 | 概念名称 | 日频维护 |
| 板块资金流 | 排行榜 | 流入、流出、净流入、净占比（按主力/超大单/大单/中单/小单） | 实时 |
| 涨停板复盘 | 榜单 | 昨日涨停/连板/首板/炸板/打二板以上表现 | 日频（盘后） |

> **亮点**：概念体系**高度紧跟热点**（含 DeepSeek概念、Kimi概念、智谱AI概念、谷子经济、低空经济等），是题材股炒作的核心导航工具。

东方财富的资金流向体系按**主力/超大单/大单/中单/小单**五档拆分，覆盖个股、板块、大盘三个层级。

**大盘资金流总览（字段）**：

| 类型 | 流入(元) | 流出(元) | 净流入(元) | 净占比 |
|---|---|---|---|---|
| 主力 | … | … | … | … |
| 超大单 | … | … | … | … |
| 大单 | … | … | … | … |
| 中单 | … | … | … | … |
| 小单 | … | … | … | … |

**个股资金流排行（字段）**：代码、名称、最新价、涨跌幅、今日主力/超大单/大单/中单/小单 净流入（净额 + 净占比），每行附「大单详情」下钻。

> **亮点**：资金流向是东方财富的**招牌特色数据**，五档拆分 + 净占比双维度 + 个股/板块/大盘三层级贯通，并可下钻到逐笔大单明细。

### 2.5 龙虎榜与游资席位 ✅ 已抓取确认

龙虎榜是东方财富最具特色的数据产品之一，提供 **5 个子维度**：

| 子维度 | 展示形式 | 典型字段 | 更新频率 |
|---|---|---|---|
| 个股龙虎榜 | 榜单 | 上榜次数、龙虎榜净买额、买入额、卖出额、总成交额（近一月/三月/六月/一年） | 日频（盘后） |
| 营业部龙虎榜 | 榜单 | 龙虎榜成交金额、上榜次数、买入额/次数、卖出额/次数、机构净买入额 | 日频 |
| 每日活跃营业部 | 排行 | 营业部名称、买入个股数、卖出个股数、买入/卖出总金额、总买卖净额、涉及股票 | 日频 |
| **席位胜率榜** | 榜单 | 营业部名称 + 上榜后1/2/3/5/10天的「买入次数、平均涨幅、上涨概率」 | 日频 |
| 北向资金席位 | 榜单 | 深股通专用、沪股通专用等专用席位的成交金额与上榜次数 | 日频 |

> **亮点**：
> - **游资席位胜率榜**：统计每个营业部上榜后 N 天的平均涨幅与上涨概率（如「深股通专用 上榜后1天 平均涨幅0.13%、上涨概率46.75%」），是极具特色的**席位跟踪/胜率分析**产品。
> - 明确区分**北向资金专用席位**（深股通/沪股通专用）与内资游资席位。
> - 每条上榜记录标注**上榜原因**（如「日换手率达到20%的前5只证券」「连续三个交易日内涨幅偏离值累计达到20%」）。

### 2.6 基金 ✅ 已抓取确认

东方财富基金频道是其**电商变现核心**（证监会批准首批独立基金销售机构），数据维度极为丰富。

| 子类 | 展示形式 | 典型字段 | 更新频率 |
|---|---|---|---|
| 基金排行/超市 | 可筛选大表 | 基金代码、简称、单位净值、累计净值、近三月/半年/一年/二年/三年/今年来/成立来 涨幅、手续费 | 日频（交易日16:00–23:00更新净值） |
| 基金分类 | 标签筛选 | 股票型 / 混合型 / 债券型 / 指数型 / QDII / FOF / 货币型 | — |
| 场内基金(ETF/LOF) | 实时净值表 | 单位净值、累计净值、增长值、增长率（含 ETF 实时市价与折价率） | 实时/日频 |
| 货币基金 | 表 | 万份收益、7日年化 | 日频 |
| 新发基金 | 列表 | 代码、名称、发行公司、基金类型、集中认购期、基金经理 | 日频 |
| 基金评级 | 榜单 | 3年期评级（上证/招商/济安金信/晨星 四家）、近1年涨幅、星级 | 日频 |
| 基金经理 | 个人页 | 在管基金、规模、业绩 | 日频 |
| 基金公司 | 公司页 | 旗下基金、规模 | 日频 |
| F10 详情 | 详情页 | 持仓、净值走势、费率、定期报告 | 日频 |

> **亮点**：多机构基金评级（上证/招商/济安金信/晨星）横向对比，是 C 端选基的重要决策工具。

### 2.7 数据中心（宏观 / 排行 / 统计） ✅ 已抓取确认

数据中心是**结构化榜单与经济统计**的聚合入口，含「我的数据」自选收藏功能。

| 子类 | 展示形式 | 典型字段 | 更新频率 |
|---|---|---|---|

| 龙虎榜/资金/股东等 | 各类榜单 | 见对应章节 | 日频 |
| 我的自选数据 | 个性化 | 用户自定义收藏的数据模块 | 用户驱动 |

> **亮点**：宏观指标（如 CPI）不仅给数值，还附**指标定义、重要性评级、数据来源（国家统计局）**，专业度与可解释性强。
