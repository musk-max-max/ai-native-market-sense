## 1. 产品原则与合规红线（贯穿全文）

### 1.1 三条不可逾越的红线

1. **不荐股、不给买卖建议**。AI 的所有输出必须是「**对公开数据的事实归纳与信息整合**」，不得出现「建议买入 / 建议卖出 / 目标价 / 值得关注可介入」等表述。预判只能表述为「资金特征 / 数据变化 / 历史统计规律」，并强制附带不确定性说明。
2. **数据必带 `as_of` 时点**。所有进入 AI 与展示层的数据，必须携带 `as_of`（数据所属交易日 / 发布时点）。AI 引用数据时必须复述 `as_of`，避免把延时数据当实时。
3. **受限数据分级控制**。沿用项目已建分级：`internal_eval`（内部评估）/ `c_end_display`（可面客展示）两级；标记为受限档的数据接口返回 **403**，AI 不得在面客侧输出受限档原始内容。

### 1.2 AI 输出的统一合规护栏

每个 AI 功能点在面客侧输出时，**必须**经过同一套后处理：

| 护栏 | 规则 |
|---|---|
| 免责声明 | 页面/卡片固定展示「内容由 AI 基于公开数据整理，不构成投资建议，数据截至 `as_of`」 |
| 词法过滤 | 拦截「买入 / 卖出 / 加仓 / 减仓 / 目标价 / 建议建仓」等指令性词；命中即改写为中性描述或拒绝 |
| 归纳定性 | 输出限定为「数据显示…」「历史统计上…」「存在…特征」，禁止将来时指令 |
| 时点标注 | 每个数据引用附 `as_of`；跨时点混用需显式说明 |
| 不确定性 | 涉及预判时，必须输出「该归纳基于历史/当前数据，不代表未来表现」 |
| 来源可溯 | AI 结论需可下钻到原始数据模块，禁止无来源断言 |

### 1.3 数据可得性标注约定（全文通用）

每个功能点统一标注三件事：

- **数据可得性**：`15000内`（tushare 15000 积分已含）/ `需另购`（独立权限）/ `缺口`（tushare 不提供）/ `外部源`（需第三方或人工）
- **更新频率**：实时 / 延时 / 日频（盘后）/ 周频 / 月频 / 季频 / 事件驱动
- **AI 输入 / 输出**：喂给模型的结构化或文本输入，与面客可见的产出

## 2. 数据可行性地基（tushare 15000 积分）

### 2.1 15000 积分内可用（无总量上限，500 次/分）

日线、复权日线；`daily_basic` 每日指标（PE/PB/PS/`dv_ratio`/换手率/量比/涨跌停状态）；财务四表 + `fina_indicator`；龙虎榜；融资融券；股东户数；十大股东；股权质押；限售解禁；大宗交易；回购；个股资金流向；沪深股通（北向）持股；公募基金持仓；宏观利率（SHIBOR/LPR/CPI 等）。

### 2.2 需独立付费（¥/期）

| 权限 | 价格 | 备注 |
|---|---|---|
| 实时日线 | ¥200/月 | 盘中行情的核心依赖 |
| 实时分钟 | ¥1000/月 | 盘中异动/盘口解读的核心依赖 |
| 指数/ETF 实时 | ¥200/月 | 大盘盘中联动 |
| 新闻资讯（快讯/长篇/新闻联播） | ¥1000/年 | AI 早报/信息面输入 |
| 公告 | ¥1000/年 | 公司事件驱动 |
| 政策法规库 | ¥1000/年 | 政策走向分析 |
| 券商研报库 | ¥500/年 | 研究观点 |
| 港股日线 | ¥1000 | 国际市场 |
| 美股日线 | ¥2000 | 国际市场 |

### 2.3 明确数据缺口（不可假装有）

- ❌ **私募持仓**：tushare 仅有公募基金持仓，**无私募 / 著名投资人持仓**。
- ❌ **实时行情（默认不含）**：实时日线/分钟/指数均为独立付费，未采购则盘中实时不可得。

> **本文档立场**：缺口必须「显式标注」或「依赖外部源 / 人工录入 / 新闻提取」，任何模块不得以占位数据伪装可得。

## 3. 板块一：专属 AI Native 页面

> 目标：超越东方财富「数据陈列」，为每个数据模块增加「AI 加工层」。每个页面定义：**AI 输入什么 → AI 做什么加工 → 用户看到什么**。

### 3.1 AI 对话入口（全局）

- **AI 输入**：用户自然语言提问 + 上下文（当前页标的、`as_of`、用户自选）；可调用的 tushare 工具（行情、`daily_basic`、财务、龙虎榜、两融、资金流等）。
- **AI 加工**：意图识别 → 选择数据工具 → 取数 → 事实归纳 → 合规护栏改写。
- **用户看到**：对话式问答卡片，每条结论附数据来源模块与 `as_of`，固定免责声明。
- **可得性**：`15000内`（工具可及部分）；实时类问答受 `需另购` 限制。
- **优先级**：**P0**。

### 3.2 个股 AI 深度解读页

- **AI 输入**：复权日线（近 N 日）、`daily_basic`（PE/PB/换手/量比/涨跌停）、财务四表 + `fina_indicator`、股东户数趋势、十大股东、股权质押、限售解禁、大宗交易、回购、个股资金流向、北向持股、所属板块资金流。
- **AI 加工**：多源结构化数据 → 生成「估值定位（含行业分位）+ 基本面变化 + 资金特征 + 风险点（质押/解禁）」的事实归纳报告；行业四分位对标（对标东方财富亮点，见 `eastmoney-data-hierarchy.md` §2.2）。
- **用户看到**：结构化解读报告（估值 / 成长 / 盈利质量 / 资金 / 风险 五段），每段附 `as_of` 与数据来源，明确「非投资建议」。
- **可得性**：`15000内`。
- **优先级**：**P0**。

### 3.3 AI 早报 / 晚报

- **AI 输入**：隔夜国际市场（指数/美股，需 `需另购` 或外部源）、宏观利率（SHIBOR/LPR/CPI，`15000内`）、自选标的昨日行情与资金流（`15000内`）、新闻/公告/政策（`需另购` 或 `外部源`）。
- **AI 加工**：聚合 → 分「隔夜要闻 / 宏观流动性 / 自选异动 / 今日关注事项」四段事实归纳；无实时权限时段点显式标注延时。
- **用户看到**：早报（盘前）/ 晚报（盘后）信息流卡片，逐条 `as_of` + 来源 + 缺口标注。
- **可得性**：混合；新闻/公告/政策为 `需另购`，国际行情为 `需另购/外部源`。
- **优先级**：早报 **P1**，晚报 **P1**。

### 3.4 AI 问答（结构化专题问答）

- **AI 输入**：专题问题（如「某行业 PE 分位」「某标的股东户数变化」「近期北向增减持」）+ 对应 tushare 数据集。
- **AI 加工**：限定在数据可支撑范围内做统计归纳，超出数据边界即明确回「该数据当前不可得」。
- **用户看到**：带数据表/图表 + 文字归纳的回答，缺口问题返回「数据缺口说明」而非编造。
- **可得性**：`15000内`为主。
- **优先级**：**P1**。

> **板块一小结**：4 个功能点（对话入口 P0、个股解读页 P0、早/晚报 P1、AI 问答 P1）。

## 5. 板块三：盘前 / 盘中 / 盘后 AI 观点

> 按交易时段切分。**盘中模块受实时权限强约束**，未采购时执行降级方案。

### 5.1 交易时段与数据权限矩阵

| 时段 | 时间窗 | 实时依赖 | 未采购实时时的降级方案 |
|---|---|---|---|
| 盘前 | 集合竞价前（约 9:15 前） | 低（以隔夜 + 昨日数据为主） | 基本不受影响，隔夜国际数据用 `需另购/外部源` |
| 盘中 | 9:30–11:30 / 13:00–15:00 | **高**（实时日线/分钟/指数） | 降级为 **D-1 延时数据 + 规则提醒**；页面显著标注「延时数据，`as_of` = 上一交易日」 |
| 盘后 | 15:00 后 | 低（以盘后日频数据为主） | 不受影响 |

### 5.2 盘前（隔夜信息 + 今日预判）

- **AI 输入**：隔夜全球指数（`需另购/外部源`）、宏观利率与 CPI（`15000内`）、昨日 A 股行情与资金流（`15000内`）、新闻/政策/公告（`需另购/外部源`）。
- **AI 加工**：聚合隔夜要闻与昨日数据 → 输出「今日关注事项清单」（如解禁、大宗、财报披露日）+ 中性事实预判。
- **用户看到**：盘前简报，逐条 `as_of` + 来源；国际行情缺口显式标注。
- **可得性**：宏观/昨日行情 `15000内`；国际/新闻/政策 `需另购/外部源`。
- **优先级**：**P1**。

### 5.3 盘中（异动解读 + 资金流监控）

- **AI 输入（实时版）**：实时日线/分钟、实时资金流向、实时指数。
- **AI 输入（降级版）**：D-1 资金流向、`daily_basic`、龙虎榜（上一交易日）。
- **AI 加工**：识别异动类型（量比放大、涨跌停、资金突变）并做事实归纳；降级版明确「基于上一交易日数据」。
- **用户看到**：异动流（实时版）或「上一交易日异动回顾」（降级版），每条 `as_of`。
- **可得性**：`需另购`（实时）/ `15000内`（延时）。
- **优先级**：降级版 **P1**，实时版 **P2**（待采购）。
- **依赖声明**：实时版需实时日线 ¥200/月 + 实时分钟 ¥1000/月 + 指数实时 ¥200/月。

### 5.4 盘后（龙虎榜复盘 + 次日策略）

- **AI 输入**：龙虎榜（上榜原因/席位/净买额）、涨停/连板梯队（由日线 + 涨跌停状态推导）、两融余额、大宗交易、北向持股变化、股东户数（季频）。
- **AI 加工**：龙虎榜复盘归纳 + 资金特征刻画 + 次日关注事项（**中性事实，非买卖策略**）。
- **用户看到**：盘后复盘报告，含「上榜原因分布 / 席位类型 / 北向变化 / 两融变化」，逐条 `as_of`。
- **可得性**：`15000内`。
- **优先级**：**P0**（盘后数据全部在 15000 内，性价比最高）。

> **板块三小结**：3 个功能点（盘前 P1、盘中 P1降级/P2实时、盘后 P0）。**盘中是唯一强依赖付费权限的时段。**

## 6. 板块四：综合形势研判

> 聚合国内国际行情 + 国内外形势 + 政策走向 + 著名投资人/私募持仓，由 AI 综合分析当前整体形势。**本板块存在结构性数据缺口，必须显式标注。**

### 6.1 子项数据可得性总表

| 子项 | 数据内容 | 可得性 | 处理策略 |
|---|---|---|---|
| 国内市场行情 | 沪深京指数日线、两融、资金流 | `15000内` | 正常接入 |
| 国际市场行情 | 美股/港股/全球指数 | `需另购`（美股 ¥2000、港股 ¥1000）或 `外部源` | 未采购则标注缺口，仅用可得的全球指数替代 |
| 国内外形势 | 宏观经济事件、地缘 | `需另购`（新闻/政策库）或 `外部源` | 缺口标注 / 新闻提取 |
| 政策走向 | 政策法规、央行利率 | `15000内`（SHIBOR/LPR/CPI）+ `需另购`（政策法规库） | 利率类正常；政策文本依赖付费/外部 |
| **著名投资人持仓** | 巴菲特 / 段永平等 | **`缺口` → 代理指标** | ❌ tushare 无 → **已决策用代理**：`top10_holders` 知名个人账户名 + 龙虎榜知名营业部席位；UI 标注「代理观察，非实际持仓」 |
| **著名私募持仓** | 高毅 / 景林等 | **`缺口` → 代理指标** | ❌ tushare 仅公募 → **已决策用代理**：`fund_portfolio`（公募重仓，机构抱团）+ `top_list`/`top_inst`（龙虎榜游资席位）；UI 标注「基于公募重仓与龙虎榜的代理观察，非私募实际持仓」 |
| 公募基金持仓 | 公募重仓股、持仓变动 | `15000内` | 正常接入（作为「机构持仓」可得部分） |

### 6.2 AI 综合研判功能

- **AI 输入**：上表所有**可得**子项 + 缺口项的显式占位说明。
- **AI 加工**：跨市场 / 宏观 / 政策 / 资金多源归纳 → 输出「当前整体形势的事实性综述」，**逐项标注数据来源与缺口**，对缺口项不做推断。
- **用户看到**：综合形势页，分「国内市场 / 国际市场 / 流动性与政策 / 机构持仓 / 数据缺口」五区；缺口区明确「该数据当前不可得，未纳入分析」。
- **合规**：仅事实归纳，不输出大势涨跌预测的投资指令。
- **优先级**：核心框架 **P1**；国际/政策/持仓缺口项的补全 **P2**（依赖采购或外部源接入）。

> **板块四小结**：1 个综合研判功能（P1）+ 1 张子项可得性总表。**标红缺口：著名投资人持仓、著名私募持仓、国际行情（未采购时）、政策文本（未采购时）。**

## 7. 板块五：A 股机构 / 游资 / 散户特征分析 + AI 预判

> 基于 tushare 多源资金/持仓数据，刻画各类资金特征，AI 整合并做**严谨、非荐股**的预判。

### 7.1 资金分类与数据映射

| 资金类型 | 刻画数据 | 来源 | 可得性 | 频率 |
|---|---|---|---|---|
| **游资** | 龙虎榜营业部席位、上榜次数、净买额、上榜原因 | 龙虎榜 | `15000内` | 日频（盘后） |
| **机构** | 公募基金持仓、十大股东中机构家数 | 公募持仓、十大股东 | `15000内` | 季频 |
| **北向（外资）** | 沪深股通持股变化、北向专用席位成交 | 沪深股通持股、龙虎榜北向席位 | `15000内` | 日频 |
| **杠杆资金** | 融资融券余额与变化 | 融资融券 | `15000内` | 日频 |
| **散户** | 股东户数变化（户数增加常对应筹码分散） | 股东户数 | `15000内` | 季频 |

> **对标**：东方财富的「游资席位胜率榜」（上榜后 1/2/3/5/10 天平均涨幅与上涨概率，见 `eastmoney-data-hierarchy.md` §2.5）为本板块可复用的统计口径参考；但 Market Sense 必须以「历史统计特征归纳」表述，不得演化为荐股。

### 7.2 AI 特征刻画与预判

- **AI 输入**：上表五类资金的结构化数据（带 `as_of`）。
- **AI 加工**：
  - 刻画各标的/板块当前**主导资金类型**（如「近期以游资席位活跃为主」）。
  - 计算历史统计特征（席位上榜后 N 日表现分布、北向增减持与价格关系等），**以历史统计口径表述**。
  - 整合为「资金结构 + 历史统计」的事实性预判，强制附不确定性声明。
- **用户看到**：资金特征分析报告 + 历史统计表；明确「历史统计不代表未来，非投资建议」。
- **合规边界**：**预判严禁转化为个股推荐**。禁止输出「该席位上榜后应跟随买入」类表述，只允许「历史上该类席位上榜后 N 日平均涨幅为 X%，上涨概率 Y%（样本量 Z，截至 `as_of`）」。
- **优先级**：游资/北向/杠杆 **P0**（龙虎榜 + 两融 + 北向，全在 15000 内且日频）；机构/散户刻画 **P1**（季频）。

> **板块五小结**：1 套资金特征刻画（游资/北向/杠杆 P0，机构/散户 P1）+ 1 套 AI 预判（含合规表述约束）。

## 9. 数据缺口与依赖清单（红标汇总）

| 缺口 / 依赖 | 影响模块 | 处理策略 |
|---|---|---|
| ❌ 私募持仓 | 板块四、板块五 | **✅ 已决策用代理**：`fund_portfolio` 公募重仓 + 龙虎榜席位；UI 强制标注「代理观察，非私募实际持仓」，不得伪装为真实持仓 |
| ❌ 著名投资人持仓 | 板块四 | **✅ 已决策用代理**：`top10_holders` 知名个人账户名 + 龙虎榜知名席位；标注代理性质，不宣称"某人持仓" |
| ⚠️ 盘中实时行情 | 板块三盘中、板块二投中实时版 | **✅ 已决策采购实时权限做实时版**（¥200–1000/月）；采购未落地则回退 D-1 延时方案并显式标注 `as_of` |
| ⚠️ 国际市场行情 | 板块四、板块三盘前 | 未采购则标注缺口，用可得全球指数替代 |
| ⚠️ 新闻 / 公告 / 政策 / 研报 | 板块一早晚报、板块二事件驱动、板块四 | 未采购则标注缺口或用外部源/新闻提取（按强依赖建议采购） |
