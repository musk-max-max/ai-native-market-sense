## 0. 一句话结论

- **✅ 强覆盖（可直接做）**：日频行情、估值指标（三档 PE/换手/量比/市值）、财务基本面、龙虎榜、融资融券、股东结构、公募基金、宏观利率——这些是**投前研究 + 盘后复盘**的完整底座。
- **⚠️ 部分覆盖（要降级或自建）**：实时盘口/盘中（需另购实时权限）、资金流五档（粒度需核对）、概念标签（远不如东方财富丰富）、游资席位胜率（需自建统计）。
- **❌ 缺口（tushare 无，必须外部源/人工/自建）**：**私募基金持仓、著名投资人持仓、股吧社区情绪**——而这三项恰是用户 AI 需求明确点名的。

## 4. 给规划的建议（按数据可得性排优先级）

**第一批（15000 内、无需另购、立即可做）——投前研究 + 盘后复盘底座：**
- 个股页：日频行情 + 三档 PE + 基本面卡 + 股东户数 + 十大股东 + 资金流向 + K 线
- 龙虎榜：明细 + 北向席位 + **自建席位胜率榜**（差异化特色）
- 涨停复盘：连板/首板/炸板（`limit_status` 自建）
- 基金：公募排行/净值/持仓
- 宏观：CPI/GDP/LPR + 新股 + 财报排行
- 融资融券/质押/解禁/大宗

**第二批（需另购独立权限，✅ 已决策采购实时权限）——盘中 + 综合研判：**
- **采购实时权限**（已决策）→ 盘中模块、盘口、异动流（实时版）
- 采购资讯/政策/研报 → 综合形势研判、盘前观点、政策解读

**第三批（数据代理/自建，✅ 私募/投资人持仓已决策用代理指标）——私募与投资人持仓、散户情绪：**
- **私募/投资人持仓：用「公募重仓 + 龙虎榜」代理指标**（已决策，标注代理性质非真实持仓）
- 散户情绪：用股东户数+小单资金流+融资余额做代理
- 概念体系：自建概念→成分股映射

> **合规提醒**：无论哪一批，所有数据展示带 as_of 时点、受限数据分级（internal_eval / c_end_display）、AI 输出不荐股——这是贯穿全部数据的硬约束。

## 5. 缺口处理决策记录（2026-11-05 用户拍板）

本节固化用户对两类关键缺口的正式决策，作为后续 PRD / 数据 / agent 落地的依据。

### 决策 D-1：私募持仓 / 著名投资人持仓 → 代理指标
- **背景**：用户 AI 需求明确点名"著名私募基金持仓""著名投资人最新持仓"，但 tushare 结构性无此数据（`fund_portfolio` 仅公募）。
- **决策**：采用**代理指标方案**，不采购外部私募数据源。
  - 私募/机构行为代理：`fund_portfolio`（公募重仓，刻画机构抱团）+ `top_list`/`top_inst`（龙虎榜席位，刻画游资活跃度）。
  - 著名投资人代理：`top10_holders` 中知名个人账户名间接捕捉 + 龙虎榜知名营业部席位。
- **强制合规标注**：代理指标反映的是机构/游资行为，**不等于真实私募或个人实际持仓**（私募季报不强制披露、无法保证覆盖到具体某人）。所有涉及 UI 必须标注「基于公募重仓与龙虎榜的代理观察，非实际持仓」，禁止宣称"某私募持有""某人买入"。

### 决策 D-2：盘中实时数据 → 采购实时权限（实时版）
- **背景**：用户需求含"投中/盘中 AI 接入""盘口解读"，强依赖实时行情；15000 积分不含实时。
- **决策**：**采购实时权限，按实时版规划投中/盘中模块**。
- **采购清单**：股票实时日线 ¥200/月 + 实时分钟 ¥1000/月 + 指数/ETF 实时 ¥200/月。
- **影响**：PRD 中"投中场景""盘口""秒级异动流"按实时能力设计，不再走日频/延时降级版；资讯/政策/研报三类独立权限本轮未单独决策，按强依赖建议采购。

> 这两项决策解除了 PRD 板块二（投中实时）与板块四（综合形势研判）的主要数据阻塞。剩余开放项：资讯/政策/研报采购、概念标签体系自建。
