# tushare 15000 积分套餐数据边界梳理

> **文档目的**：梳理 tushare Pro「15000 积分」套餐到底能提供哪些数据、哪些数据需要额外独立权限、哪些数据 tushare 根本没有（需外部源补充）。作为「market sense」H5 平台数据规划与 AI 需求可行性判断的依据。
> **信息来源**：tushare 官方文档（`tushare.pro`）权限列表与各接口文档，抓取日期 2026-11-05。
> **适用套餐**：15000 积分 = ¥1500/年（当前最高常规积分档）。

---

## 1. 积分制度核心规则

tushare Pro 采用积分分级制：

| 积分档 | 价格（元/年） | 常规数据调取 | 特殊说明 |
|---|---|---|---|
| 120 | 0（注册即得） | 仅非复权日线等极少数接口 | 门槛最低 |
| 2000 | 200 | 基础投研接口 | — |
| 5000 | 500 | 扩展投研接口 | — |
| 8000 | 800 | 更多接口 + 更高频次 | — |
| 10000 | 1000 | 接近全量常规接口 | — |
| **15000** | **1500** | **常规数据基本无总量限制，500 次/分钟** | **本平台规划档位** |

**关键规则**：
1. **积分是分级门槛，不消耗**——达到某积分档即可调取该档及以下的接口，调用本身不扣积分。
2. **积分档决定「频次」和「是否有总量上限」**：越高档，每分钟请求数越高（15000 = 500 次/分），且多数常规数据「无总量限制」。
3. **特色数据是「独立权限」，与积分档无关**——即使 15000 积分，特色数据也要单独申请/付费开通。
4. **盘中/实时行情不在积分体系内**——是独立权限，按月或按年单独付费。

## 2. 15000 积分可直接使用的数据（无需额外付费）

以下接口在 15000 积分档可调取，按投研用途归类。括号内为最低积分门槛（均 ≤ 15000，故全部可用）。

| 接口 | 最低积分 | 内容 |
|---|---|---|
| `daily` 日线 | 120 | A 股日线（开高低收、成交量额、振幅） |
| `weekly` / `monthly` 周/月线 | 2000 | 周/月 K 线 |
| `pro_bar` 复权行情 | 2000 | 前复权/后复权/不复权日线、周线、月线 |

> **注意**：以上均为**日频收盘数据**。**实时行情、分钟行情不在积分内**（见第 3 节）。

### 2.2 每日基本面指标（选股核心）
| 接口 | 最低积分 | 关键字段 |

## 3. 需要额外「独立权限」的数据（15000 积分不包含，需单独付费）

这些是**特色数据或实时数据**，即使 15000 积分也不能调，必须到 tushare「权限中心」单独申请开通。对「market sense」AI 需求影响最大的几类：

### 3.1 实时/盘中行情（对「盘中 AI 观点」是硬依赖）
| 数据 | 价格 | 说明 |
|---|---|---|
| 股票实时日线行情 | ¥200/月 | 盘中实时最新价/涨跌幅 |
| 股票实时分钟行情 | ¥1000/月 | 盘中分钟 K 线/Tick |
| 指数实时日线 | ¥200/月 | 盘中指数实时 |
| ETF 实时行情 | ¥200/月 | 盘中 ETF 实时 |
| 历史分钟行情 | ¥2000 | 历史分钟回补 |

> **结论**：用户需求里的「**盘中 AI 接入**」「盘口五档/逐笔」依赖实时权限。**若不采购实时权限，「盘中」模块只能做延时/降级方案**（用日频数据 + 延时快照），必须在 PRD 里明确这个依赖，不能假装有实时数据。

### 3.2 资讯/研报/政策（对「综合形势研判」「盘前观点」是硬依赖）
| 数据 | 价格 | 说明 |
|---|---|---|
| 新闻资讯（快讯/长篇新闻/新闻联播） | ¥1000/年 | 财经快讯、深度新闻、新闻联播文字稿 |
| 上市公司公告 | ¥1000/年 | 公告全文/标题 |
| 政策法规库 | ¥1000/年 | 政策文件、法规文本 |
| 券商研究报告库 | ¥500/年 | 券商研报（对标东方财富研报） |
| 盘前股本结构 | ¥500/年 | 盘前股本变动 |
| 互动易 / e互动 | ¥500/年 | 上市公司投资者互动问答 |
| 集合竞价数据 | ¥500/年 | 竞价阶段数据 |
| 央行货币政策执行报告 | ¥200/年 | 货政报告文本 |
| 港股日线（历史） | ¥1000 | 港股历史日线 |
| 美股日线（历史） | ¥2000 | 美股历史日线 |

> **结论**：用户需求的「综合国内外形势 + 政策走向 + 券商观点」强依赖资讯/政策/研报三类独立权限。**不采购则 AI 无法基于 tushare 拿到政策文本和新闻语料**，只能靠人工录入或其他免费源。

## 4. tushare 数据 vs 东方财富数据层级对照（速览）

| 东方财富数据大类 | tushare 15000 覆盖度 | 说明 |
|---|---|---|
| ① 沪深京行情（实时） | ⚠️ 部分 | 历史日线 ✅；**实时/盘中需独立权限** |
| ② 个股详情（盘口五档/三档 PE/换手） | ⚠️ 部分 | `daily_basic` 有三档 PE/换手/量比/市值 ✅；**盘口五档/逐笔成交需实时权限** |
| ③ 板块/行业/概念 | ⚠️ 弱 | tushare 有行业分类，但**概念标签体系远不如东方财富丰富** |
| ④ 资金流向（五档拆分） | ⚠️ 部分 | `moneyflow` 有资金流向 ✅；**五档（超大/大/中/小单）拆分粒度需核对，秒级大单异动需实时** |
| ⑤ 龙虎榜与游资席位 | ✅ 强 | `top_list`/`top_inst` 有明细；但**游资席位胜率榜需自建统计**（tushare 不直接给胜率） |
| ⑥ 基金（公募/ETF/FOF） | ✅ 强 | `fund_*` 系列覆盖公募/ETF；**无私募** |
| ⑦ 数据中心（宏观/排行） | ✅ 强 | `cpi`/`gdp`/`lpr` 等宏观 ✅ |
| ⑧ 债券/期货/外汇/全球 | ⚠️ 部分 | 历史日线 ✅；**全球市场实时需独立权限** |
| ⑨ 资讯/股吧/研报 | ⚠️ 部分 | **股吧社区 tushare 无；资讯/研报需独立权限** |

## 5. 数据缺口（用户需求点名但 tushare 无，必须外部源或自建）

| 用户需求项 | tushare 是否提供 | 缺口处理建议 |
|---|---|---|
| **著名私募基金持仓** | ❌ 无 | tushare `fund_portfolio` 只有公募。私募持仓需外部数据源/爬取/人工录入，或用「公募重仓 + 龙虎榜席位」作代理指标 |
| **著名投资人（个人）最新持仓** | ❌ 无 | 无任何数据源。只能靠新闻提取/公告十大股东（`top10_holders` 中若出现知名个人账户名可间接捕捉） |
| **股吧/社区情绪** | ❌ 无 | 东方财富股吧是社区，tushare 无。情绪分析需外部源 |
| **盘口五档/逐笔 Tick** | ❌（积分内无） | 需实时权限；不采购则做不了 Level-1 五档盘口 |
| **游资席位胜率榜** | ⚠️ 需自建 | tushare 有龙虎榜明细，但「营业部上榜后 N 天涨幅/胜率」需平台自己回溯统计 |
| **丰富概念标签** | ⚠️ 弱 | 东方财富概念体系庞大（AI/低空经济/中特估等），tushare 行业分类较粗；概念标签可考虑用申万行业 + 自建概念映射 |

## 6. 给 AI 需求文档的关键依赖提示（PRD 写作必读）

1. **盘中实时模块 = 实时权限硬依赖**：投中场景、盘口解读、秒级异动，都需采购实时行情（¥200–1000/月）。不采购则必须降级为日频/延时设计。
2. **资讯/政策/研报 = 综合研判硬依赖**：综合形势、政策解读、盘前观点需采购资讯(¥1000/年)+政策法规(¥1000/年)+研报(¥500/年)。
3. **私募/著名投资人持仓 = 数据缺口**：PRD 里这部分要标红为「数据不可得/依赖外部源」，不能假装有。
4. **可立即落地（15000 内、无需另购）**：日频行情、daily_basic 估值、龙虎榜、两融、资金流、公募持仓、财务四表、宏观利率——这些是**投前研究 + 盘后复盘**的底座，可先做。
5. **合规贯穿**：所有数据展示带 as_of 时点，受限数据分级（internal_eval / c_end_display），AI 输出不得荐股。
