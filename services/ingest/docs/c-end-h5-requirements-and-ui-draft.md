## 0. 一句话定位

**移动端优先的 A 股「market sense」查看器**：3 屏内回答「今天市场怎么样 / 这只股票怎么样 / 它的基本面值不值这个价」，所有数值带来源、时点与免责，**不做交易、不做荐股、不做实时盘口**。

## 0.1 前置闸门（必须先满足）

- **真栈部署验收**：`warehouse-load` 的 ECS 真栈链路是当前唯一验收闸门；本方案 S1/S2 均排在它之后。
- **F1 授权（硬边界）**：官方书面授权未取得前，C 端恒为合规受限态（`403 / internal_eval`），**不展示任何 tushare 来源的数值**；本方案不构成放行依据，真实数据只允许进开发/测试库。
- 本迭代**不建 UI、不写前端代码**，仅作为 P1 backlog 输入。

## 1. 目标与非目标

### 目标（首版）
1. 一部手机、单手握持（375–430 px），从首页到个股核心数据 ≤ 2 次点击。
2. 首屏只呈现「今天/当前」最关键的 3–6 个数字，其余按需展开，**默认不滚动就能读懂**。
3. 数据口径透明：每个价格区都带 `as_of`、来源、复权口径与免责；过期有明确标识。
4. 兼容现有 P0 竖切片：搜索、个股页、自选、四态文案与合规出口清单不变。

### 非目标（首版不做）
- 实时逐笔/Level-2 盘口、分时成交明细、五档买卖（数据授权与 SLO 不支持）。
- 交易/开户/组合持仓；任何形式的买卖建议、目标价、评级。
- 社区/股吧/资讯流（后期另立项目）。
- 港股/美股/期货/基金频道的完整行情。
- 后台可配置的运营位（首版用静态配置，不建 CMS）。

## 2. 用户与场景

| 用户 | 场景 | 首屏诉求 | 关键动作 |
| --- | --- | --- | --- |
| 泛投资者（主要） | 通勤/午休快速看一眼 | 大盘温度 + 自选股涨跌 | 打开→扫→关，< 30 秒 |
| 持仓者 | 收盘后复盘 | 个股价、涨跌幅、成交额、估值 | 搜索代码/名称 → 个股页 |
| 研究型用户 | 初筛基本面 | PE/PB/市值/ROE/营收净利同比 | 个股页 → 财务卡 → 切换报告期 |
| 新用户 | 不了解代码格式 | 按名称/拼音搜索 | 搜索联想 → 进入个股 |

**核心用户旅程（P0）**：首页搜索（代码或简称）→ 个股页首屏（名称/最新价/涨跌幅/as_of/来源/免责）→ 下滑看关键指标 → 财务摘要 → 返回/加自选。

## 3. 信息架构（3 + 1）

```
底部 Tab（3）
├── 首页      市场温度 + 搜索 + 自选预览
├── 行情      A 股列表（可排序/筛选）
└── 自选      已关注列表（本地 + 后续账户同步）
隐藏页
├── 个股详情  /stocks/:instrumentId（P0 主路由，/stock/:id 别名）
└── 404 / 错误态
```

- 个股页不是 Tab，从任何列表/搜索进入，返回保持来源位置（滚动位置恢复）。
- 首页与行情页都内嵌同一搜索入口；搜索框固定顶部 → 首屏可达。

## 5. 交互与「更简洁」的具体规则

1. **一屏一个任务**：首页=看市场+搜索；列表=扫；个股=判读。禁止在个股页堆资讯/社区/推荐。
2. **数字优先**：价格用 28–34 px 等宽数字（`--font-mono`），涨跌用颜色+符号双编码（不只靠颜色，照顾色弱）。
3. **红涨绿跌**（A 股惯例），但颜色不单独承载信息：`+2.31%` / `-1.08%` 必须带符号。
4. **只保留 1 个强调色**（现有 `--accent` 墨绿）；涨跌色仅用于数值，不做背景大面积铺色。
5. **二级信息折叠**：振幅、内外盘、五档、成交明细等默认不出现；「查看更多指标」进入详情 sheet。
6. **所有图表默认不复权并显式标注**；切复权时数值与口径同步更新，避免截图误读。
7. **无数据即无数字**：缺字段显示「—」并附说明入口？**不**——合规要求受限态不得出现 `--`；仅在「已授权但该字段未收录」时用中性说明文案（由 `copy.ts` 统一）。
8. **手势**：下拉刷新（收盘后 >15 分钟才允许手动刷新）；左右滑动切换个股上一只/下一只（P1，需防误触）。
9. **性能**：首屏 JS < 180 KB gzip，LCP < 2.5 s（4G），数字字体不阻塞渲染；列表虚拟滚动（P1）。

## 6. UI 方案（视觉与布局）

### 6.1 设计原则
- **克制**：白底/深底两类表面 + 1 强调色；卡片只用于「可操作/可分组」的内容，不用装饰性阴影。
- **对齐**：4 pt 网格；页面左右 16 px；卡片内 16 px；列表行高 56 px（触控 ≥ 44 px）。
- **层次**：只用字号/字重/颜色三档建立层级，不用边框堆叠（现有 `--radius: 14px`）。
- **可信**：`as_of`、来源、免责使用弱化但可读的 `--text-muted`，始终可见；不用「最后更新」这类模糊措辞。

### 6.2 复用现有 token（`web/h5/src/styles/tokens.css`）
- 背景 `--bg`、卡片 `--surface`、分隔 `--border`；正文 `--text`、次要 `--text-muted`。
- 涨 `--up`（红）/跌 `--down`（绿），均提供 weak 背景用于标签；对比度满足 AA。
- 字体：正文系统无衬线；数字 `--font-mono`；行高 1.4–1.5。
- 暗色模式随系统，不单独提供开关（首版）；后续由 A10 design-tokens 统一接管。

## 8. 合规与文案约束（不可协商）

1. 所有用户可见文案来自 `web/h5/src/lib/copy.ts`（`COPY_VERSION` 单一轴）；本草案中的中文仅为需求描述，不是最终文案。
2. 四态：正常 / 受限 403 / 429 / 断网 / 5xx。**403 不展示任何价格数字、`0`、`--`、骨架数字位**；不提供重试按钮。
3. `meta.disclaimer` / `meta.source` / `as_of` 原样展示，不折叠、不可关闭；403 时免责仍展示。
4. 产物不得含厂商名、`internal_eval`、`entitlement`、`tier`、`积分` 等内部标识；`data-source` 只能用契约公开枚举。
5. 埋点仅 `instrumentId/route/uiState/action`，不接第三方。
6. 不出现「推荐/建议买入/目标价/稳赚/必涨」等表述；行情页不写投资建议。
7. 数据未授权（F1）期间：受限态即上线态，页面表现为合规 403 文案，不放任何数值。

## 9. 验收标准（设计评审版）

- [ ] 首屏 6 元素齐全，且 375 px 宽无需滚动
- [ ] 首页无任何占位/示例价格数字
- [ ] 个股页只有 1 个主 CTA（加自选），无交易/推荐入口

- [ ] `as_of`/来源/免责在行情块内常驻；过期有 `StaleBadge`
